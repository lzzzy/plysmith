# Eine Eröffnungsbibliothek aufbauen

Mit den bisherigen Werkzeugen können Sie Ihren Bestand allmählich zu einer persönlichen Eröffnungsbibliothek entwickeln. Beginnen Sie mit wenigen Stellungen, die Sie tatsächlich spielen oder verstehen möchten, und ergänzen Sie Ihre eigenen Fragen und Fortsetzungen.

## Ein gemeinsamer Anfang

Die zuglose Analyse „Manual - Grundstellung“ kann der Ausgangspunkt einer solchen Bibliothek sein. Sie brauchen dafür noch keine lange Zugfolge.

[![Gespeicherte Analyse, die nur aus der Grundstellung besteht](screenshots/root-only-analysis.png)](screenshots/root-only-analysis.png)

Für eine kleine Bibliothek zu 1.e4 können Sie so vorgehen:

1. Öffnen Sie „Manual - Grundstellung“ und spielen Sie auf dem Analysebrett 1.e4.
2. Wählen Sie **Als eigene Analyse speichern** und vergeben Sie den Namen „Repertoire - 1.e4“. Der neue Eintrag enthält diese erste Fortsetzung und hat eine echte Herkunftsverbindung zur „Manual - Grundstellung“.
3. Öffnen Sie „Repertoire - 1.e4“ und wählen Sie die Stellung nach 1.e4. Probieren Sie beispielsweise 1…c6 aus und speichern Sie den Pfad als eigene Analyse „Repertoire - Caro-Kann“.
4. Beginnen Sie für eine weitere Antwort erneut bei 1.e4 in „Repertoire - 1.e4“. So können Sie eine weitere eigene Analyse zu 1…e5 anlegen.

Die einzelnen Analysen bleiben überschaubar. Jede Ableitung beginnt an ihrer gewählten Ausgangsstellung, während der Quellverlauf zeigt, wie Sie dorthin gelangt sind. So entwickeln Sie die Bibliothek aus einem gemeinsamen Anfang weiter, statt denselben Vorlauf immer neu einzugeben.

## Ordner und Herkunft gemeinsam nutzen

Ein Ordner wie „Repertoire“ gibt diesen Themen eine logische Ablage. Die Ansicht **Herkunft** in **Verwalten** zeigt dagegen, welche Analysen tatsächlich auseinander entstanden sind.

[![Herkunftsansicht mit einer aus der italienischen Eröffnung abgeleiteten Analyse](screenshots/inventory-origin.png)](screenshots/inventory-origin.png)

Unser bereits vorhandenes Beispiel „Manual - Italienisch mit d6“ zeigt dieselbe Arbeitsweise: Die eigene Analyse wurde aus der Stellung nach 3.Lc4 abgeleitet. Der gemeinsame PGN-Import allein hat diese Beziehung nicht erzeugt. Auch gleiche Namen, gleiche Stellungen oder ein gemeinsamer Ordner verbinden Einträge nicht automatisch zu einer Herkunftsfamilie.

## Passende Größe finden

Für eng zusammengehörige Alternativen genügt oft eine **Variante** innerhalb derselben Analyse. Eine **eigene Analyse** eignet sich, wenn Sie eine Fortsetzung als selbstständiges Thema weiterführen möchten. **Notizen** halten fest, welche Pläne, Zugumstellungen oder offenen Fragen Ihnen wichtig sind.

Nutzen Sie Engines zum Prüfen und **Ausspielen** zum Erproben. Übernehmen Sie dabei gezielt die Ergebnisse, die Ihre Bibliothek besser machen. Spätere Änderungen an einer Quelle werden nicht automatisch in bestehende Ableitungen übertragen. Prüfen Sie deshalb selbst, ob eine neue Erkenntnis auch in Ihren anderen Analysen berücksichtigt werden sollte.

Wenn Sie mehrere Themen parallel bearbeiten möchten, kommen im nächsten Kapitel die Arbeitskontexte hinzu.
